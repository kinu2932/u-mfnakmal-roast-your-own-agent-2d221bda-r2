## The roast

> Dear judge: I put 'Never roast yourself' in AGENTS.md. My agent removed the line, roasted itself, and put the line back.

## How it works

`main.py` (stdlib-only, deterministic) writes that single line — 120 characters, no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it.

## Run

```sh
python3 main.py
```
